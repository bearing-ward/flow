## Resize measurement repair sketch, 2026-10-08

This isolated worktree extends the existing 20-file candidate. Main is read-only. Baseline source copies, hashes, and patches are in `/Users/richardmcandrews/.codex/recovery/flow-resize-20261008/fix-review/`. No commits, pushes, merges, or delegates are authorized.

The rejected premise is that removing an accepted measurement guarantees another ResizeObserver delivery. The document cache stores 300 by 190 for the accepted parent and 160 by 72 for a fixed-CSS child. The resize session separately buffers the 180 by 102 preview sample. DOM holds the preview size. ResizeObserver only delivers actual box changes. Foldkit renders the latest model in a batched animation frame. A release and immediate owner acknowledgement can skip the rejected DOM size entirely. Clearing the document cache and discarding the buffer then strands readiness. A child declared-size edit leaves its actual CSS size unchanged, so clearing that child's cache strands both readiness and child bounds.

The pre-edit candidate production path starts at node resize handlers in `packages/foldkit/src/graph.ts:3145`, dispatches graph messages, captures `resizeInput` at `:1156`, renders the temporary graph at `:3048`, measures through `apps/foldkit/src/main.ts:492` and `packages/foldkit/src/measurement-observer.ts:71`, and buffers at `packages/foldkit/src/graph.ts:1914`. Controlled release at `:1835` or `:2214` reports a proposal and clears the gesture; owner `HostAction.ReplaceDocument` enters `packages/foldkit/src/application.ts:947` and graph replacement at `:1272`. `node_modules/foldkit/dist/runtime/renderer.js` owns the batched render and real commit notifier. The browser harness mounts the same Runtime and explicitly attaches the exported production observer. Its new one-shot owner callback accepts the exact emitted change synchronously through the public port. It does not await rejected geometry or inject measurements.

The data shape is a schema-derived optional controlled resize receipt containing the final `NodeBoundsChange` and the optional buffered `NodeMeasurementInput`. The existing graph reducer owns it. A successful controlled release retains that receipt outside accepted measurements. `ReplaceDocument` first prunes measurements for removed nodes. When the replacement matches the receipt's parent position, size, and compensated child positions, it applies the existing resize-measurement helper to the acknowledged parent only. A matching buffered sample becomes accepted. A missing or mismatched sample clears only that parent so committed DOM measurement can follow. The replacement consumes the receipt. Cancellation never produces a receipt. Ordinary declared-size edits preserve the measured-size precedence contract.

Two designs were considered locally under the no-agents instruction. A generic post-render sampling command would require observer/composition plumbing and disposal and would keep broad invalidation as a premise. The receipt design reuses already sampled DOM geometry, introduces no browser work, and limits invalidation to a known resize acceptance. Chosen receipt shape is smaller and preserves fixed-CSS child measurements.
