## Conformity and deviations

- **Conforming outcomes:** configurable canvas interactions and all six example outcomes, bounded by `closing-options.e2e.ts` and `closing-recipes.e2e.ts`. Native sidebar dragging must create a node at the transformed drop point; export must produce a decoded PNG with expected dimensions.
- **Intentionally different:** existing Vanilla key defaults and modifier options remain compatible; explicit React key-code options override them. Deletion stays scoped to canvas focus. `renderOnlyVisible` and `keyboardActivation` keep their Vanilla names. Canvas callbacks retain Vanilla payloads. Existing aggregate connection callbacks also observe click connections; the new click callbacks report only click lifecycle. Auto-pan retains Flow's 40px band and constant per-frame displacement. Reconnect anchors retain Vanilla's default radius 8 unless configured. Styles use `FlowStyle`. Recipe renderers are DOM/SVG and subscriptions rather than React components/hooks. Empty-pane release deletes the edge; cancellation preserves it. Export is an app dependency and a native download. React-only attribution/proOptions/debug are omitted because Flow has no React branding or store debugger; width/height belong to the supplied root element. Prior Plan 115 stacking, preview/commit and styling deviations remain.
- **Unverified:** side-by-side React runtime and pixel parity; full multi-host release acceptance. Focused verification and the complete Vanilla suite are separate evidence boundaries.
