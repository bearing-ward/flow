The implementation follows `plans/archive/native-generation-blocker-design.md`, SHA256 `0caa4409a78b57beea61a3946955be56d2f79d49e364d19cc908d66f5b9e4483`, approved by independent and primary architecture review. The serialized reducer compares them and uses existing advanceNodeMeasurementGeneration to issue the next generation. It never trusts a caller-selected next generation. A mismatch is stale; absent node is missing; wrong instance is owner-mismatch. Replay cannot advance twice.
- An invalidate request identifies an issued lease by node,instance,generation. Only that exact current lease may advance to a tombstone; stale invalidation cannot affect its replacement.
- Every accepted document removal invalidates its old node generation before sample pruning. Put this in one Graph reducer document-transition boundary with an unchanged-document-reference fast path, including public replacements, commands and transactions. Controlled proposals do not invalidate before acknowledgement. Preserve document/viewport/revision/semantic notification behavior.

Require connected current elements inside the captured owner and the nearest matching native canvas; no global lookup or nested foreign owner. Retire removed MutationRecords even when an element is reinserted within the same delivery, observe node-ID changes, and reject old resize callbacks. Restart prepares the current core generation rather than restarting a local counter.

A new registration client owns request correlation, bounded disposal/draining and resource cleanup; its protocol must specify late responses, timeout/send failure and subscriber teardown. No predicted-generation invalidation, permanent subscriber/timer retention or second graph authority.

Prepare returns prepared with nullable current generation and instanceId; register returns registered with the actual lease; invalidate returns invalidated.
