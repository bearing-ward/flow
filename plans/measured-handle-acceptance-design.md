## Native architecture decision

One generation-tagged measurement authority projects detached schema-derived geometry. Graph declarations own handle identity, kind and side. Measured output owns node-local center, dimensions and owner ID. The native shape deliberately avoids optional/null duplicate state. Measurement status distinguishes usable declared/default fallback from current DOM samples. Measurements stay out of saved v1. Current hidden samples retain measured dimensions while handles are emptied; never-measured hidden nodes use declared/default fallback. Nullable connection-handle semantics remain owned by Plan 067 and are not changed or closed by this ID mapping. This design proposes differences on those merits, subject to primary review, rather than renaming unsupported semantics to clear acceptance.

Browser proof will use the existing mounted public fixtures in all three hosts, extend the shared handle contract, and register a new member acceptance case in each measured-geometry suite. Numeric field evidence will assert actual DOM rectangles, both kinds, every side and zoom 0.5/2. Structural absence and empty collections are observable public assertions. Installed positive/negative probes bind declarations independently of workspace typechecking. Unit tests only prove runtime decoding/fallback invariants and are labeled accordingly. Callback scheduling comparison remains a reviewed native facade difference, not exact React timing equivalence.
