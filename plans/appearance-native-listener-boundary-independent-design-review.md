This is a native representation boundary with a platform-owned contract. Installed TypeScript `C/node_modules/typescript/lib/lib.dom.d.ts:11489` declares callable EventListener; `:11493` declares EventListenerObject.handleEvent. MediaQueryList extends EventTarget at `:20171`; the public callable and union overloads are `:20200` and `:20201`. The probe derives its listener from `Parameters<MediaQueryList['addEventListener']>[1]`, keeps the real target/listener identities, excludes null from recording, and forwards the original argument list to the bound native method. See N Vanilla e2e `:308`, `:339`, `:348`, `:351`, `:357` and `:382`; Vue `:370`, `:401`, `:410`, `:413`, `:419` and `:444`; Foldkit `:1225`, `:1256`, `:1265`, `:1268`, `:1274` and `:1299`.

Callable precedence matters. Web IDL first asks whether the listener object is callable. Only a noncallable listener resolves handleEvent, and that branch changes the receiver to the listener object. DOM supplies the event's current target for the callable branch. The retained probe preserves that distinction with `record.listener.call(record.target, event)` versus `record.listener.handleEvent(event)`. A callable with a handleEvent property must still use the callable branch. The official algorithms support this reasoning: [Web IDL callback invocation](https://webidl.spec.whatwg.org/#call-a-user-objects-operation), [DOM inner invocation](https://dom.spec.whatwg.org/#concept-event-listener-inner-invoke).

The imported Effect predicate is unavailable in this exact serialized callback. Installed Playwright `C/node_modules/.bun/playwright-core@1.62.1/node_modules/playwright-core/lib/coreBundle.js:61316` passes page.addInitScript through evaluationScript; `:57230` serializes a function with toString and its explicit argument. These three calls supply only the browser function. Module imports do not become that function's browser lexical environment. The [official page.addInitScript documentation](https://playwright.dev/docs/api/class-page#page-add-init-script) describes execution in the page before page scripts. Replacing the guard with an inaccessible import would break the test. Injecting a module or adding an exposed function/bundle would introduce another mechanism outside this correction. A realm-dependent instanceof substitute would also change the contract being tested.

The deliberate late invocation is TEST-only. The probe constructs a MediaQueryListEvent from the actual retained target's current matches/media and calls the removed listener directly. It does not reproduce the browser dispatch algorithm, native event trust, target/currentTarget assignment, or naturally queued late delivery. This limitation is correctly documented.
