##069: schema factory and persistence — BLOCKED getter/codec boundary

Proposed export `createFlowDataContract({nodeVariants,edgeVariants})` accepts registries keyed by the actual node.type/edge.type discriminator. Each registry entry contains a caller data schema with JSON-object encoded side; factory derives discriminated Node/Edge/Document/SavedDocument/SavedSession unions whose `type` literal correlates with that entry's data type. No independent union nodeData disconnected from node.type: compile positive/negative tests must reject `{type:'customer',data:invoiceData}` and narrow customer data in renderer/selectors/callbacks. A default-key entry handles omitted type; unknown type produces a typed decode failure, not any widening. Base identity/geometry/graph integrity is invariant. Omission of the contract retains existing concrete JSON APIs.

Three boundaries are explicit: (1) `decodeEncodedDocument(unknown)` uses full factory schema to decode encoded fields once and validate core graph integrity; (2) `validateDecodedDocument(candidate)` validates factory decoded side and integrity for internal/owner updater candidates without rerunning encoded-to-decoded transformations; (3) `encodeDocument(decoded)` validates decoded side, runs caller encoders, validates complete encoded JSON body, then writes supported versioned persistence envelope. Saved restore uses encoded decode, not base concrete FlowDocument decoder on transformed data. Geometry functions receive structural base graph fields on the same decoded typed records; edit/connection/reconnection/utility/selector/delete functions are parameterized by factory contract and validate decoded candidates at publication. Default concrete public operations remain the default contract implementation. Effect schemas requiring services expose those requirements in returned Effect environments; hosts receive/provide the required Layer at composition, or factory rejects unsupported serviceful schema with a typed configuration failure. No hidden runSync without services and no erased base decoder used to coerce custom data back into JsonObject.

Accepted authority is exactly one decoded contract graph; encode-derived JSON is a boundary result, never a second store. Caller transformed values are permitted only when clone/freeze/snapshot preservation is defined: existing `flow-snapshot.ts:49-54` structuredClone loses custom prototypes and rejects functions. Replace typed-contract snapshot cloning with contract-aware encode then decode through the required Effect services, yielding detached schema-valid data, followed by supported immutability policy. Legacy JSON contract may retain existing structuredClone fast path. Mutable Date/Map/custom class internal slots are not made immutable by Object.freeze. Adopt codec-detached-per-exposure policy: each public read/listener/updater/callback receives its own encoded-then-decoded detached graph; ordinary arrays/plain records recursively freeze, while mutable transformed class values are detached without claiming deep immutability of internal slots. Mutating a Date/class within one view cannot mutate accepted authority or another listener's view. No cache reuses that class instance across public deliveries. Effect serviceful codec failures settle typed read/update failures and emit no accepted publication; native composition handles async codec scheduling explicitly. Unsupported encode/decode-detach schemas fail typed configuration before mounting; no silently lost prototype. Tests cover Date/class transforms, encoder failure, service requirement, wrong discriminator/data, reentrant updater and frozen/detached snapshots. No any/unchecked coercions may make inference appear sound.

Required runtime capture is typed-data preservation, not TypeScript inference: new `scripts/capture-typed-data-reference.ts`, `research/harnesses/typed-data/`, `research/fixtures/typed-data-reference.json`, `packages/conformance/src/typed-data-reference.test.ts` are mandatory, with two stable pinned captures of add/change/reconnect/selector/delete/save-restore data.
