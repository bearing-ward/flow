# Planning artifact names

Only executable numbered plans use root filenames matching `0NN-*.md`. Reviews, execution histories and design supplements use descriptive nonnumeric prefixes. The member checker reads root numbered Markdown files into an owner-plan map; duplicate numbers can select a supplement instead of the executable plan. This convention prevents the reproduced079 metadata collision without changing the checker or weakening ownership requirements.

On2026-09-30 the new067/069/077/078 supplements were renamed, and current plan/probe links were updated. Existing historical frozen candidate records retain their original snapshots. During final assembly, copied065supplementary reviews/designs must also use nonnumeric names and their proof links must remain valid. Canonical numbered plans retain their numbers and original requirements.
