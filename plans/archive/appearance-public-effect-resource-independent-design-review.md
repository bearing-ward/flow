## Blocking revisions

Design `plans/archive/appearance-public-effect-resource-composition-design.md:11` justifies the restriction through Tracer's never service identifier, and `:27` requires a negative named-service Layer argument. The actual Effect declaration at candidate `node_modules/effect/src/Layer.ts:54` is `Layer<in ROut, out E = never, out RIn = never>`. A fully built `Layer<NamedService, never, never>` is therefore assignable to `Layer<never, never, never>`: providing extra services satisfies a consumer that requires none. `Layer.succeed` returns `Layer<I>` for the supplied key at `node_modules/effect/src/Layer.ts:1074`. A negative compiler assertion that such a layer is rejected would be unconsumed, not proof of a restricted public contract. Tracer being a Reference with identifier never is true, but does not make this an exact-output restriction.

   Required correction: keep the optional `Layer.Layer<never>` parameter if the intended contract is no new required factory services, no construction error channel, and no external construction dependencies. Explicitly acknowledge that extra provided context services are accepted under Effect's authoritative contravariance, while createProgram's inferred Runtime requirements remain never. Replace the ambiguous named-service negative with an actual external RIn requirement, for example an official Layer construction that requires a named service to build. Also require a non-never E negative and primitive/non-Layer negative, with correctly placed consumed `@ts-expect-error` directives in the real installed declaration compiler. A fully provided named-output layer must not be presented as rejected; an explicit compiler positive can record that behavior. Do not add a cast, output whitelist, invented tracer service, broader generic factory or runtime required-service logic to force an impossible negative test. If exact provided-output exclusion is actually wanted, it needs a separately reviewed different API rather than a claim that this signature enforces it.

2. Make installed-public tracer use and resource release unconditional observed assertions.
