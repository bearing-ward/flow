## Exact native registry proposal

Common **native-only** context: readonly `{ id: string; name: string; references: readonly { edgeId: EdgeId; endpoint: 'start'|'end' }[] }`. id is an opaque owner-allocation token; references come from effective visible accepted edges after defaults and are detached/frozen. No graph data, DOM selector, mutable accepted edge or persisted ID is delivered. Reserved names arrow/arrowclosed cannot override legacy built-ins; empty name rejects. Other arbitrary nonempty strings are logical names, including punctuation; they never become CSS syntax or raw DOM IDs. Own undefined registry entries mean unregistered.

**Vanilla:** add `markerDefinitions?: Readonly<Record<string, FlowMarkerDefinitionFactory | undefined>>` only to native FlowMountOptionsInput, outside FlowMountOptionsSchema. Export factory `(context: FlowMarkerDefinitionContext & {readonly ownerDocument: Document}) => FlowMarkerDefinitionInstance`; instance has `readonly element: SVGMarkerElement`, `readonly update: (context: FlowMarkerDefinitionContext) => void`, and `readonly destroy: () => void`. Native createEdgeRenderer owns the definitions layer and lifecycle. Registry is a creation input like existing renderer registrations; no new setter or mutable graph option is invented. Document/default/reference updates invoke update; owner remount changes registration factories. This creation-lifetime policy is a proposed native difference, not dynamic registry parity.

**Vue:** FlowCanvas adds native `markerDefinitions?: Readonly<Record<string, FlowVueMarkerDefinitionRegistration | undefined>>`. Registration contains optional `attributes: Readonly<Omit<SVGAttributes,'id'>>` and optional native `component: Component`; `markerDefinition` slot receives the common context plus those attributes/component and returns native VNode children. Adapter owns `<marker :id>` and keyed SVG placement; component/slot renders **children**, not a competing marker root. Component receives common context. Slot overrides component when provided; an entry without component is valid only when the slot supplies content. Attributes support the full native SVG/style/event surface, not a marker-field whitelist; id is reserved at runtime as well as type level. A component's mounted/updated/unmounted lifecycle is the Vue resource lifecycle. Reactive registry/attribute/component/slot changes reconcile by owner/name/generation.
