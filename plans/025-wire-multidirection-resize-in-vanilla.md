## Why this matters

The vanilla host exposes only a selected node's lower-right button. Wiring all directions through one core candidate lets left/top resize reposition nodes without splitting a semantic change or leaving edges at stale anchors. The browser contract must cover controlled ownership, cancellation, nested positions, and cleanup.

## Steps

1. Add a schema-derived atomic node-bounds change carrying local position and declared size, plus an apply function that preserves unaffected nodes. Keep existing `node-size` for its already published lower-right path unless a complete caller migration is explicitly reviewed. Extend `FlowInteractionSemanticEvent` and the resize-session outcome so the host can publish the selected change kind without bypassing the session gate. Add unit tests for decode, apply, missing node, and persistence round trip. **Verify:** `bun run typecheck` and focused core Vitest exit 0.
2. Render eight directional controls on selected nodes with distinct accessible names and data-direction values. Begin one `node-resize` session recording direction and original local position/size. Suppress node drag, connection, and pane pan from a resize control. **Verify:** browser test finds eight labeled controls and no unintended movement change on pointerdown.
3. Use Plan 024's pure geometry for preview and commit at zoom 1 and 2. Update transient position and measurements together; recompute incident edges, toolbar anchors, culling, and minimap. On completion emit one semantic candidate; in controlled mode restore authoritative position/size until update, in uncontrolled mode adopt both. **Verify:** browser tests assert exact left, top, and corner bounds, edge path movement, and one change per completed gesture.
4. Route Escape, blur, pointercancel, capture loss, relevant node removal, and destroy through the existing cancellation path. Restore both position and size and release capture once. Check nested child bounds and parent extent in a browser. **Verify:** focused browser test exits 0 with no stale preview or post-destroy change.
5. Update gesture guide, trace, and only the checklist items fully proved. Regenerate summary through `bun run research:inventory`. **Verify:** full gate and `git diff --check` exit 0.
