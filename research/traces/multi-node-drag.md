The common snap offset is calculated at `packages/system/src/xydrag/utils.ts:126`. Changed positions are sent as one drag-item map with `dragging: true`; no callback fires when positions did not change at `packages/system/src/xydrag/XYDrag.ts:201`. ## Conformity and deviations

- **Conforming:** Dragging one selected Flow node moves every selected group member by the same flow-space delta while leaving an unselected node still. Core unit tests prove the geometry and atomic document transition; the Flow browser test proves transient DOM movement and the final semantic change. No test compares live upstream output.
- **Intentionally different:** Flow uses native pointer capture and one final semantic `node-positions` change. The reference uses d3 drag and publishes a batch during movement and again on stop. The vanilla adapter owns pointer lifecycle, and controlled callers acknowledge the final change.
- **Unverified:** Controlled pointer group drag, non-draggable members, selection-overlay dragging, snapping, extents, auto-pan, cancellation, and parity against a live pinned reference remain unverified. The pinned shared Playwright suite does not directly assert group displacement.
