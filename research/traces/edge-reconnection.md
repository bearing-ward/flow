## Conformity and deviations

- **Conforming behavior:** Flow retains the opposite endpoint, validates the released handle, and updates the edge only for a valid changed endpoint. Core and browser tests establish this for Flow.
- **Intentionally different:** Flow preserves edge ID and publishes one schema-derived change. React delegates application to a callback and its helper replaces IDs by default; Svelte merges into its store.
- **Unverified:** Reference snap radius, auto-pan, touch, custom validators, callback order, and output parity have no direct pinned browser comparison.
