## Conformity and deviations

Conformity is bounded to the unchanged pinned Cypress and Playwright ports, local Chromium native mouse/CDP input, computed styles, and retained transforms. Acceptance counts are recorded in [Plan 136](../../plans/136-cypress-interaction-policy.md). An existing Foldkit Flow test still expects a raw node-click report with every interactivity switch off and no callback client (`apps/foldkit/e2e/events-and-changes.e2e.ts:244`). The public API documents this behavior (`docs/public-api.md:417`), while pinned NodeWrapper makes the wrapper non-interactive in that state (`packages/react/src/components/NodeWrapper/index.tsx:90`, `packages/react/src/components/NodeWrapper/index.tsx:206`). That documented conflict remains unresolved; the selected Foldkit suite did not pass.

Intentionally different internally: framework-owned lifecycle and DOM code, Effect workflows, Foldkit's typed event ports and callback client, and controlled document acknowledgements. Functions never enter the Foldkit Model. Existing non-interactive edge labels, Vanilla shared-SVG stacking, hidden Foldkit toolbars, and marker IDs retain their documented differences.

Unverified: live React runtime comparison, other browser engines, physical devices, full-profile integration/release acceptance, and collector-side OTLP delivery. The focused verifier is not a broad parity claim.
