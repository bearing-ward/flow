## Conformity and deviations

- **Conforming behavior:** Flow exposes an edge name, tab focus when enabled, keyboard selection and deletion, and a separate wide hit path. Browser tests establish these Flow outputs; reference browser tests establish only deletion, custom label, nonselectability, and wide-hit behavior.
- **Intentionally different:** Flow uses `role="button"` with `aria-pressed` for selectable edges and `role="img"` for nonselectable edges. xyflow uses a group or image role and shared instructions. Flow's default name uses node labels rather than node identifiers; this is more legible to a user.
- **Unverified:** Screen-reader announcements, automated accessibility auditing, and direct Flow-to-xyflow keyboard and visual parity have not been tested.
