# Reusable canvas UI boundary

## Reference source path

The pinned xyflow React adapter defaults its `Background` to dots and scales the pattern with the viewport transform; variant, gap, color, and background color are component inputs (`packages/react/src/additional-components/Background/Background.tsx:19`, `packages/react/src/additional-components/Background/Background.tsx:37`, `packages/react/src/additional-components/Background/Background.tsx:53`). Its Controls render zoom, fit, and an interactivity toggle (`packages/react/src/additional-components/Controls/Controls.tsx:25`, `packages/react/src/additional-components/Controls/Controls.tsx:45`, `packages/react/src/additional-components/Controls/Controls.tsx:60`, `packages/react/src/additional-components/Controls/Controls.tsx:101`). The reference pane enables double-click zoom by default and passes that setting into the zoom pane (`packages/react/src/container/ReactFlow/index.tsx:99`, `packages/react/src/container/ZoomPane/index.tsx:111`).

The reference minimap computes visible-node bounds plus the current viewport rectangle (`packages/react/src/additional-components/MiniMap/MiniMap.tsx:19`, `packages/react/src/additional-components/MiniMap/MiniMap.tsx:41`), and its SVG delegates click coordinates to its minimap geometry (`packages/react/src/additional-components/MiniMap/MiniMap.tsx:151`, `packages/react/src/additional-components/MiniMap/MiniMap.tsx:189`). Panels are positioned DOM children above the viewport (`packages/react/src/components/Panel/index.tsx:16`, `packages/react/src/components/Panel/index.tsx:41`). Node toolbars render into a portal and position from node bounds (`packages/react/src/additional-components/NodeToolbar/NodeToolbar.tsx:108`, `packages/react/src/additional-components/NodeToolbar/NodeToolbar.tsx:118`, `packages/react/src/additional-components/NodeToolbar/NodeToolbar.tsx:129`); edge toolbars render through the edge-label portal (`packages/react/src/additional-components/EdgeToolbar/EdgeToolbar.tsx:48`, `packages/react/src/additional-components/EdgeToolbar/EdgeToolbar.tsx:60`).

## Flow production path

`mountFlow` decodes `FlowMountOptionsSchema` before acquiring the host (`apps/vanilla/src/mount-flow.ts:94`, `apps/vanilla/src/mount-flow.ts:4070`). The host assigns the optional background pattern and CSS variables to its canvas (`apps/vanilla/src/mount-flow.ts:385`, `apps/vanilla/src/mount-flow.ts:386`); stylesheet rules implement dots, lines, and no pattern (`apps/vanilla/src/style.css:26`, `apps/vanilla/src/style.css:38`, `apps/vanilla/src/style.css:42`). `createCanvasUI` creates opt-in accessible zoom/fit/select-pan buttons, a minimap and an optional caller-provided panel slot (`apps/vanilla/src/canvas-ui.ts:21`, `apps/vanilla/src/canvas-ui.ts:38`, `apps/vanilla/src/canvas-ui.ts:59`, `apps/vanilla/src/canvas-ui.ts:76`). It does not clone caller content when the graph reconciles and restores a previously attached panel on host destruction (`apps/vanilla/src/canvas-ui.ts:121`). The mode toggle changes transient host state. Pan mode uses a capture-phase pointer handler to start viewport pan before node and edge handlers; it skips UI overlay targets, so controls, panels and caller toolbars retain their pointer behavior (`apps/vanilla/src/mount-flow.ts:2799`, `apps/vanilla/src/mount-flow.ts:3894`). Keyboard movement remains available because keyboard handlers do not consult pointer mode (`apps/vanilla/src/mount-flow.ts:3140`).

Zoom buttons and double-click use core `zoomViewportAt`, then send the result through the host's viewport change path (`apps/vanilla/src/mount-flow.ts:3868`, `apps/vanilla/src/mount-flow.ts:3880`). That path clamps zoom and pan extent, renders the viewport, and preserves controlled acknowledgement (`apps/vanilla/src/mount-flow.ts:1881`, `apps/vanilla/src/mount-flow.ts:1888`). Double-click anchoring converts the event point from canvas screen coordinates and the core math preserves that flow point while zoom changes (`apps/vanilla/src/mount-flow.ts:3870`, `packages/core/src/domain/flow-runtime.schema.ts:626`). The minimap is built from `createFlowGraph` geometry and `graphBounds`, including declared/measured dimensions and current position overrides (`apps/vanilla/src/mount-flow.ts:614`, `apps/vanilla/src/mount-flow.ts:621`, `packages/core/src/domain/flow-graph.ts:125`). Minimap clicks request a viewport centered on the selected graph fraction through the same semantic viewport path (`apps/vanilla/src/canvas-ui.ts:67`, `apps/vanilla/src/mount-flow.ts:3889`).

Toolbar geometry stays in core `flowToolbarAnchors`; the host filters anchors to rendered nodes and edges and calls `onToolbarAnchors` (`packages/core/src/domain/flow-toolbar-anchor.ts:15`, `packages/core/src/domain/flow-toolbar-anchor.ts:45`, `apps/vanilla/src/mount-flow.ts:638`). Callers may provide node and edge container elements keyed by ids. The host positions those existing elements, hides them when their graph item is culled or missing, preserves their buttons, and restores the elements on destroy (`apps/vanilla/src/canvas-ui.ts:90`, `apps/vanilla/src/canvas-ui.ts:136`, `apps/vanilla/src/canvas-ui.ts:147`). The demo's duplicate toolbar layer was removed when controls/minimap became reusable. Pane pointer-down ignores UI overlay targets so buttons and minimap clicks do not begin a pan (`apps/vanilla/src/mount-flow.ts:2706`).

## Flow test path

The browser suite mounts through `/src/public.ts`, checks background settings and accessible labels, exercises double-click and control zoom at the configured maximum, verifies minimap node/viewport geometry and navigation, captures a stable screenshot, verifies pan mode over a node preserves node transform and selection while moving the viewport, confirms controls still work in pan mode, then checks panel and caller toolbar preservation across a keyed update, viewport change, culling, and destroy (`apps/vanilla/e2e/canvas-ui.e2e.ts:4`, `apps/vanilla/e2e/canvas-ui.e2e.ts:26`, `apps/vanilla/e2e/canvas-ui.e2e.ts:61`, `apps/vanilla/e2e/canvas-ui.e2e.ts:93`). This suite tests Flow's vanilla adapter only; it does not mount a pinned reference fixture with equivalent inputs.

## Conformity and deviations

| Classification | Behavior | Reason and evidence boundary |
| --- | --- | --- |
| Conforms | Dot/line/no-pattern background options, zoom controls, fit, double-click anchoring, and viewport navigation are optional host UI over a session viewport. | Flow uses CSS and `zoomViewportAt`; browser assertions cover options, names, anchor, limits, and minimap navigation. |
| Intentionally different | Flow's minimap draws simple node rectangles and centers the viewport on a click. It has no reference-style mask, node customization, pannable or zoomable modes. | This is a small first UI layer; only the Flow browser scenario is verified. |
| Intentionally different | Flow's select/pan toggle changes transient host pointer behavior: pan mode pans primary pointer drags over canvas, nodes and edges without selecting, connecting or resizing; it does not persist to the document or disable keyboard commands. | The browser case verifies a node-body drag pans without changing node geometry or selection and confirms controls retain pointer behavior. Equivalent reference output was not run, so this is not a direct parity claim. |
| Intentionally different | A caller passes a panel element and retains its contents; Flow does not implement a general overlay portal or panel placement API. | The browser test proves keyed-update persistence, not a cross-adapter portal contract. |
| Conforms | Caller-owned node and edge toolbar elements can be positioned from anchor geometry without replacing caller buttons. | The browser case checks both types of container, viewport repositioning, culling visibility and restoration on destroy. |
| Unverified | Reference toolbar selection and visibility behavior. | Flow has no automatic selected-only toolbar policy; caller containers are explicit by graph id. |
| Unverified | The pinned reference's visual output and interaction parity with Flow. | No equivalent shared fixture ran against both adapters, and no reference screenshot was captured in this slice. |
