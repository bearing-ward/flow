## Conformity and deviations

Conforming: declared dimensions and instance-owned default custom labels match the unchanged pinned cases at the local Chromium browser boundary recorded in Plan 141. Native Foldkit batches preserve the initial callback count tested upstream. The separate dimension regression proves the update output without treating the still-failing complete UP-128-044 case as passing.

Intentionally different: the 150 by 44 unmeasured geometry fallback, standard non-interactive edge labels, Vanilla shared-SVG stacking, Foldkit hidden toolbars, marker IDs, culling overscan and omitted attribution retain their existing policies. Default theme appearance beyond the declared boxes is not changed to mimic React. No new intentional-difference ledger entry is introduced.

Unverified: live React execution, arbitrary cross-frame mount batching, other browser engines, physical devices, full-profile acceptance, CI, deployment and collector-side OTLP delivery. Source inspection supplies causes; only the named browser and unit assertions supply acceptance.
