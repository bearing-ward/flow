## Conformity and deviations

- **Conforming behavior:** Selected-edge deletion removes the keyed SVG output in uncontrolled mode, and `deletable: false` blocks removal. Flow core and browser tests establish this for Flow; the pinned suite establishes corresponding reference DOM behavior.
- **Intentionally different:** Flow publishes one `edge-remove` change from a focused edge and accepts both `Delete` and `Backspace`. xyflow defaults to global `Backspace` and exposes deletion callbacks, a public delete API, node cascade, and a before-delete hook. Flow keeps this slice limited to one selected edge.
- **Unverified:** Direct cross-run output parity, input-focus suppression outside the focused edge, node cascade, and the reference callback sequence remain outside this test boundary.
