## Conformity and deviations

- **Conforming at the tested local Chromium boundary:** built-in labels activate their edge and use its semantic stacking level; portal labels default to no pointer events. The 2026-10-22 decision supersedes the historical noninteractive-label policy. UP-126-014 and the host overlap regressions are the acceptance boundaries.
- **Intentionally different representation:** Flow retains HTML string labels; React measures SVG text inside its edge group. Rich React content and exact text/background pixels remain outside this change.
- **Unverified:** pixel placement against the pinned adapters, collision handling, and live React runtime interaction beyond the unchanged upstream port boundary.
