## Shared public contracts and state

`workflowAiSettingIssues` at `packages/workflow/src/workflow-ai-settings.ts:7` validates model IDs, temperatures, and image sizes against decoded capabilities. Issues name the node and stable setting field. `workflowValidationReport`, `createWorkflowExecutionPlan`, and `prepareWorkflowExecution` accept optional capabilities at `packages/workflow/src/workflow-preparation.ts:103`, `packages/workflow/src/workflow-preparation.ts:238`, and `packages/workflow/src/workflow-preparation.ts:361`. `startWorkflowRun` accepts the same capabilities at `packages/workflow/src/workflow-runner.ts:168`, so unsupported settings fail preparation before a run emits events. The default base evaluator still requires explicit AI composition.

`WorkflowEvaluation.onText` at `packages/workflow/src/workflow-runner.ts:27` carries cumulative text to the runner, which adds run ID, accepted revision, and node ID. Running events can contain text at `packages/workflow/src/workflow-execution.schema.ts:49`. The runner freezes events and ignores callbacks after node settlement. The reducer at `packages/workflow/src/workflow-run-state.ts:32` accepts running text updates but rejects another run, another revision, an obsolete accepted revision, terminal sessions, and invalid node transitions. Completion still carries schema-decoded, frozen outputs.

Run state, streams, service instances, and output remain transient. Saved workflow configuration, history, clipboard fragments, and room documents retain only accepted semantic data. Central run/node/AI/decode span names are reused. Run spans include run ID and revision, node spans include node ID, and failure logs retain diagnostic codes. There are no per-chunk logs. Application composition still owns OTLP export and flushing. Collector delivery remains unverified.

## Conformity and deviations

- Conforming to adopted Unit 7 and D1–D8: shared provider-backed text/image evaluation, typed settings and ports, independent configuration, per-node status, local preview, incremental text, failure, cancellation, rerun, and scoped cleanup. Dedicated package, real three-host browser, transport, and packed-consumer checks define the tested boundary.
- Intentionally different: the fixed provider emits fixture text and an original local PNG, accepts no credentials, and makes no generation-service calls. Typed panels, incremental output, cancellation, sequential DAG scheduling, and local persistence follow the adopted Flow decisions. Spatial groups and document collaboration do not create executable subworkflows or distributed runs. Embedded data URLs avoid temporary object-URL ownership.
- Unverified: private upstream template source and subscriptions, commercial models and settings, upstream streaming/failure/cancellation semantics, exact appearance and generated content, React/Svelte workflow hosts, live provider delivery, durable jobs, run resumption, and collector-side OTLP delivery. Functional catalog closure is not a broad reference-parity or full-suite claim.
