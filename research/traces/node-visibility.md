## Conformity and deviations

- **Conforming:** Hidden node DOM is absent while the document record remains; a live update restores rendering and observation.
- **Intentionally different:** Flow always suppresses edges connected to hidden nodes, following the explicit Svelte rule. The pinned React path may retain an edge when cached or declared endpoint geometry remains available.
- **Unverified:** The pinned browser fixture does not test connected hidden-node edges or live updates. Flow's checks establish its own output, not React parity. Large-scale visibility churn remains unmeasured.
