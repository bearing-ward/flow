Effect v4 · Vanilla · Vue · Foldkit

Graphs, in your framework.

Flow is an Effect v4 graph canvas with Vanilla, Vue, and Foldkit hosts. Build node editors with a shared, validated graph model, browser interactions, and optional integrations for routing, layout, and workflows.

Open the playground ↗Read the docs

An independent project in active development. Host capabilities differ; these demos do not establish full React Flow parity.

Run it locally

Start with a canvas

The packages are currently private workspace archives. Clone the repository to try the tutorial. See the first canvas tutorial and public API guide for the complete example.

Install and start

git clone https://github.com/bearing-ward/flow.git
cd flow
bun install --frozen-lockfile
bun run dev

Open http://127.0.0.1:4173/.

Mount with the public API

import { createFlow } from '@flow/vanilla'
import '@flow/vanilla/style.css'

const controller = await createFlow(root, {
  nodes: [
    { id: 'a', label: 'Hello',
      position: { x: 80, y: 120 } },
  ],
  edges: [],
}, {
  documentMode: 'uncontrolled',
  viewport: {
    mode: 'uncontrolled',
    initial: { x: 0, y: 0, zoom: 1 },
    limits: { minZoom: 0.5, maxZoom: 2 },
  },
})

// Release browser resources when unmounting.
controller.destroy()
