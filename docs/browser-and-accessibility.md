# Browser support and accessibility checks

The checked-in Playwright suite currently runs in Chromium. It verifies DOM output, pointer workflows, keyboard actions, accessible roles and names for nodes and controls, focus behavior, `aria-pressed` state, and teardown. Vanilla-specific coverage includes all eight resize-control names and keyboard directions, Escape restoration, native button/link activation, input/select/textarea editing, inherited `contenteditable`, custom drag-handle and no-drag behavior, and focus/action preservation for caller panels and portals. The [canvas UI tests](../apps/vanilla/e2e/canvas-ui.e2e.ts), [gesture tests](../apps/vanilla/e2e/advanced-gestures.e2e.ts), [renderer tests](../apps/vanilla/e2e/graph-renderers.e2e.ts), [gesture option tests](../apps/vanilla/e2e/gesture-options.e2e.ts), and [shared adapter conformance tests](../packages/conformance/src/index.test.ts) are the evidence for those claims. Feature-specific vanilla evidence is not a Vue or Foldkit conformance result; the adapter-specific test boundary is summarized in [the fixture guide](../research/fixtures/README.md#capability-and-evidence-matrix).

The repository does not currently run a Safari or Firefox matrix, a screen-reader test, or a mobile-device touch suite. Chromium tests exercise deterministic cancellation by Escape, blur, pointer cancel, capture loss, removal, and destroy; resize cancellation checks restored geometry, released capture, no semantic change, and a fresh gesture. The native concurrent-pointer and two-contact pinch cancellation cases remain marked `test.fixme`: this Playwright/CDP environment does not preserve native pointer capture for those cases, and no device harness is configured. Native multi-pointer cancellation therefore remains unverified. These limits are not evidence of support or failure in other browsers.

The current accessibility boundary is automated role/name/focus and keyboard behavior in Chromium. Keyboard resize tests cover all eight named resize buttons, edge direction, focus retention, cancellation, controlled acknowledgement, and the rule that resize arrows do not move the node. Renderer tests check native Enter/Space activation counts, link focus after Enter, text editing and arrow ownership, and Escape behavior while no Flow gesture is active. This is a Chromium keyboard interaction check, not a complete WCAG audit or screen-reader review. Before a public release, add manual keyboard-only and screen-reader review, plus browser coverage for the browser versions the project chooses to support.
